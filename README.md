# similitudo.eu

Sources of the [similitudo.eu](https://similitudo.eu) website: the brand front of similitudo, numerical methods and
GPU-accelerated simulation software for research projects.

- **Generator:** [Astro](https://astro.build) 7, static output.
- **Hosting:** GitHub Pages, built and deployed by GitHub Actions on every push to `main`
  (`.github/workflows/deploy.yml`); the site is public, the repository private.
- **Domain / DNS:** Cloudflare. `public/CNAME` holds the custom domain.
- **Identity:** sumi × architecture (look B4 of the look lab, `docs/look-lab-brief.md`): plaster / sumi-charcoal
  tokens and type in `src/styles/global.css`; the mark is a blast front drawn as an ensō over an adaptive quadtree,
  generated by `src/lib/mesh/` (live in the home hero, `src/components/HeroMesh.astro`; still frames via
  `src/components/MeshStill.astro`). The vermilion seal (`src/components/Seal.astro`) is the only colour and is shared
  with ADAM, FLUME and PRISM (`~/fortran/adam/docs/BRAND.md`).

## Develop

One entry point, `./site` (run it alone for the list):

| Command | What it does |
|---|---|
| `./site dev` | live editing at http://localhost:4321, drafts shown, reloads on save |
| `./site prod` | production build served at http://localhost:4322 (Ctrl-C stops): exactly what GitHub Pages publishes |
| `./site check` | builds, then tests every page at 390 and 1440 px, light and dark: no console errors or failed requests, no horizontal scroll, nav links not covered, internal links resolve, no lab or draft content in `dist/`. Exit 1 on any problem: run it before a push |
| `./site shots` | builds, then writes a screenshot sheet of every page (desktop and phone) to `shots/index.html` (gitignored) |
| `./site og` | regenerates `public/og.png`, the 1200×630 card shown when a link to the site is shared, from the home hero |
| `./site fresh` | stops the dev server and clears Astro's caches: use when `dev` shows errors that `check` does not (a stale content cache after a schema change) |

`prod`, `check` and `shots` take `--no-build` to reuse the last build. `dist/` is served by a small static server inside
`scripts/site-check.mjs`, not by `astro preview` (in Astro 7 that runs as a single background service per project). They drive the Chromium cached by Playwright
(`~/.cache/ms-playwright/chromium-*`) or `$CHROMIUM_PATH`; `playwright-core` is pinned to the version that matches it.
The same commands exist as `npm run dev | prod | check | shots`.

## Content

| What | Where | Format |
|---|---|---|
| Codes | `src/content/codes/*.md` | frontmatter + body |
| Projects | `src/content/projects/*.md` | frontmatter + body |
| People | `src/content/people/*.md` | frontmatter + body |
| Publications | `src/data/publications.yaml` | one keyed entry each |

Projects, Publications and Contact are parked until they have real content: see `docs/TODO.md`.

Schemas live in `src/content.config.ts`; a missing or malformed field fails the build. Set `draft: true` to keep an
entry out of production while still seeing it in `npm run dev`. Search for `TODO` to find unfinished copy.
